# Scarface
Encoder/Decoder Tool

### Run
```
go run main.go
```

### Build an .exe
```
go build -o scarface.exe main.go
```
### >_ Features
- Base64 encode/decode
- Hex encode/decode
- URL encode/decode
- ASCII encode/decode
- Binary encode/decode
- HTML encode/decode
- Caesar encode/decode
- MD5 encode
- JWT decode
- Web Interface
- Command Line Interface
